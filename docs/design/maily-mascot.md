# Mascot Design: Maily

Maily is the official mascot of **Neon Sandbox Pro**. She is a digital sprite that lives within the recursive modules and helps users craft perfect emails.

## Visual Identity

| Feature | Description |
| :--- | :--- |
| **Form** | A futuristic, aerodynamic envelope-drone with glowing neon wings. |
| **Primary Colors** | Neon Cyan (`#00E5FF`) for the body, Neon Pink (`#FF007F`) for the accents. |
| **Eyes** | Digital "dot-matrix" eyes that change expression (Happy, Thinking, Success). |
| **Vibe** | "Cyber-retro" (Synthwave) but professional and efficient. |

## Role in the App

- **AI Guide**: Maily appears in the `GeminiChatPanelV48` to represent the AI assistant.
- **Success Messenger**: She pops up with a neon trail when a module is successfully exported.
- **Recursive navigator**: She "flies" into nested blocks when you select a path.
